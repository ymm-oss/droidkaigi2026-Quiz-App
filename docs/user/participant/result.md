## 表示内容

| 項目 | 説明 |
|------|------|
| **ニックネーム** | ホームで入力した名前 |
| **正解数** | `正解数 / 全問数` |
| **スコア** | 正解数と時間ボーナスから算出（数字はアニメーション表示） |
| **ランキングへ** | 当日ランキング画面へ遷移 |

スコアの計算式は [開発者向け・採点ロジック](/developer/scoring) を参照してください。
