# ランキング

当日の正解率順の一覧です。

<img src="/screenshots/android/android-ranking.png" alt="ランキング画面" width="280" />

## 表示内容

| 項目 | 説明 |
|------|------|
| **順位・ニックネーム・正解率** | 当日の Top N（**選んだ公開フォルダごと**。`n%`。複数選択・並び替えは近い答えほど高い） |
| **クイズの種類** | 公開フォルダが複数あるときは切り替えて、フォルダ別のランキングを見られます |
| **自分の行** | ホームで入力したニックネームと一致する行をハイライト |
| **回答完了日時** | `MM/dd HH:mm` 形式。取得できない場合は「不明」 |
| **ホームへ** | ホーム画面に戻る |

## 注意点

- 表示対象は **当日分** かつ **フォルダごと** のエントリです
- 同じ問題セット（回答したフォルダ）の行が、他の参加者が完了すると一覧に追加されます
- 回答中に運営が公開フォルダを切り替えても、結果のランキングは自分が解いたセットのままです
- 本番ではランキングの取得・結果送信にネットワークが必要です
