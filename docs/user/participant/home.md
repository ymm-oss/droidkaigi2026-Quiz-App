# ホーム

ニックネームを入力してクイズを開始する画面です。

## できること

| 操作 | 説明 |
|------|------|
| **言語切替** | System / 日本語 / English。UI と問題コンテンツを切り替えます。端末内に保存され、次回起動時も維持されます |
| **ニックネーム入力** | ランキングに表示される名前。空のまま開始するとエラーになります |
| **クイズの種類** | 公開フォルダが複数あるときは、スタッフが設定した公開名・公開説明（一般向け・高難易度など）から選びます。1 件だけのときは表示されません |
| **クイズ開始** | 選んだ問題セットを読み込み、クイズ画面へ遷移します。サイトが非公開、または公開フォルダが 0 件のときは開始できません |

## 注意点

- 受付中にスタッフがサイトを非公開にすると、Home を開きっぱなしでも開始できなくなります（プレイ中の出題は変わりません）
- ニックネームはランキング上で自分の行を見つける手がかりになります
- 本番環境では問題の読み込みにネットワークが必要です。失敗時はエラーメッセージが表示されます
