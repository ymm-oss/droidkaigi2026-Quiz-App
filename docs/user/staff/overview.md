# 管理者アプリ概要

運営スタッフ向けのコンソールです。会場 PC の Desktop アプリ（`:staffDesktopApp`）に加え、参加者 Web と同じ Firebase Hosting の隠し URL `/staff` からもログインして使えます。セキュリティは URL 隠しではなく Firebase Authentication です。レイアウトはデスクトップ幅前提です。

## 主な機能

| 機能 | 内容 |
|------|------|
| **クイズの管理** | 問題の追加・編集、解説、形式ごとの設定。参加者プレビュー（スマホ枠、日本語 / 英語） |
| **フォルダの管理** | 日付・難易度など用途別にクイズセットを分ける。参加者向けに公開するフォルダは複数同時に指定できる |
| **サイト公開** | 参加者アプリの受付 ON/OFF（`sitePublished`。フォルダ公開とは別） |
| **ランキングの参照** | フォルダごとの当日ランキング確認 |

## 画面一覧

| 画面 | 説明 |
|------|------|
| [ログイン](/user/staff/auth) | スタッフ認証 |

::: tip
本番では Firebase Authentication でログインし、データは Firestore に保存されます。詳細なデータ構造は [開発者向け・Firestore](/developer/firestore) を参照してください。
:::
