# 管理者アプリ概要

運営スタッフ向けの Desktop アプリです。会場 PC から問題セットと公開状態を管理します。

## 主な機能

| 機能 | 内容 |
|------|------|
| **クイズの管理** | 問題の追加・編集、解説、形式ごとの設定。参加者プレビュー（スマホ枠） |
| **フォルダの管理** | 日付・難易度など用途別にクイズセットを分ける。参加者向けに公開するフォルダ（アクティブフォルダ）の切替 |
| **サイト公開** | 参加者アプリの受付 ON/OFF（`sitePublished`。フォルダ公開とは別） |
| **ランキングの参照** | フォルダごとの当日ランキング確認 |

## 画面一覧

| 画面 | 説明 |
|------|------|
| [ログイン](/user/staff/auth) | スタッフ認証 |
| [運営コンソール](/user/staff/console) | クイズ編集・公開・ランキング |

::: tip
本番では Firebase Authentication でログインし、データは Firestore に保存されます。詳細なデータ構造は [開発者向け・Firestore](/developer/firestore) を参照してください。
:::
