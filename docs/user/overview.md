# 利用者向け概要

DroidKaigi 2026 の会場で使うクイズ関連アプリは **2 系統** あります。

## アプリの種類

| アプリ | 対象 | 主なプラットフォーム | できること |
|--------|------|----------------------|------------|
| **参加者アプリ** | 来場者 | Android / Desktop（Web は整備中） | ニックネーム入力 → クイズ解答 → スコア確認 → 当日ランキング |
| **管理者アプリ** | 運営スタッフ | Desktop のみ | 問題・フォルダの編集、公開切替、ランキング参照 |

## 参加者の流れ（要約）

1. **ホーム** — 言語切替とニックネーム入力、クイズ開始
2. **クイズ** — 単一選択 / 複数選択 / 並び替えに回答。回答後は正誤フィードバック
3. **結果** — 正解数とスコアを表示
4. **ランキング** — 当日の Top N。自分の行がハイライトされる

詳細は [画面の流れ](/user/participant/flow) を参照してください。

## 管理者の流れ（要約）

1. **ログイン** — スタッフ用アカウントで認証
2. **コンソール** — フォルダ（クイズセット）の選択・編集、公開中フォルダの切替
3. **ランキング** — フォルダごとの当日ランキングを確認

詳細は [管理者アプリ概要](/user/staff/overview) を参照してください。

## ネットワークについて

会場の本番運用では、問題の取得とスコア送信に **オンライン接続が必要** です。オフラインのみでの完走は想定していません。
